 ## 2. 模板选择

 - **选用模板**：[academicpages/academicpages.github.io](https://github.com/academicpages/academicpages.github.io)
 - **备选方案对比**：
   - *SuperDesign*：前端设计辅助工具，可自动生成样式但无法直接输出 Jekyll 模板，不适用于 GitHub Pages 部署流程
   - *modern-resume-theme*：简历主题，侧重于单页 CV 展示，缺少 Portfolio 和时间线布局模块
   - *Academic Pages*：学术风格、内置 About / CV / Portfolio 模块、移动端响应式、深色模式支持、可直接部署到 GitHub Pages——最终选择此模板
 - **选用原因**：
   - 学术风格适合展示教育背景、项目经历和研究成果
   - 内置 About、CV、Portfolio 等模块，无需从零搭建
   - 移动端友好，响应式布局实现完善（hamburger menu、自适应断点）
   - 深色模式支持（跟随系统设置）
   - 可直接部署到 GitHub Pages，无需服务器或复杂构建环境
   - MIT 开源许可，允许自由修改和二次发布
 - **保留内容**：布局框架、响应式样式、导航结构、深色模式支持、Font Awesome 图标库
 - **修改内容**：
   - 全部示例内容替换为 Shelly Zhong 真实信息
   - 主题色改为蓝绿色马卡龙风格（主色 #5B8C8C，辅色 #F5F0EB）
   - 首页 About 改为时间线布局（2024 年入学至今的关键节点）
   - 导航精简为 Home / Projects / CV / Contact 四项
   - 头像替换为漫画风格（隐私保护）
   - 邮箱和电话做部分脱敏处理
   - 清理模板自带的无关联邦文件（talkmap.ipynb、docker-compose.yaml、.devcontainer/ 等）

 | 内容替换 | 读取模板结构，批量替换 _config.yml、_pages/、_portfolio/、_data/ 中的示例内容；撰写真实项目描述 | 逐项审核 About 时间线内容、实习经历描述、技能分类；确认邮箱/电话脱敏格式 |

 | 迭代修正 | 根据平台反馈逐轮修复：清理模板占位图、精简仓库、补充截图、添加证明材料 | 确认每轮修改的优先级；在终端执行 git commit/push |
 | 文档编写 | 生成并迭代 PRD、Design、Checklist、Final Report；根据 Checklist 逐项验证并标记完成 | 审核全部文档内容、补充个人信息细节、签署验收清单 |
 | 提交调试 | 排查 vibe-submit CLI 不可用、Python 版本不兼容（3.10→3.13）、网络超时等问题；通过 MCP 协议直连提交服务器 | 提供作业码 QZCO05EU；在终端辅助执行命令 |

 ### AI 协作中的关键决策

 1. **隐私保护优先**：使用漫画风格头像替代真实照片，邮箱和电话做 `XXX` 脱敏，不公开身份证号、住址等敏感信息
 2. **文档驱动开发**：先编写 PRD → Design → Checklist 三份规格文档，再基于文档验收网站实现，确保内容与设计一致
 3. **迭代式修正**：每轮修改后根据反馈重新评估，共经历 7+ 轮迭代（模板清理 → 内容填充 → 样式调整 → 截图补充 → 隐私处理 → 仓库精简 → 文档完善）

 ### 遇到的问题与修复记录

 | 问题 | 影响 | 修复方式 |
 |------|------|----------|
 | Portfolio 页面使用 .html 后缀导致 Markdown 内容以纯文本显示 | 项目卡片无法正常渲染 | 重命名为 .md 后缀 |
 | 模板自带大量占位图片和示例内容 | 网站显得未完成 | 逐一替换为真实照片、项目截图 |
 | 仓库体积过大（含 talkmap.ipynb 等无关文件） | 不专业、不易维护 | 删除模板自带的无关联邦文件和目录 |
 | vibe-submit CLI 在终端不可用 | 无法提交作业 | 通过 MCP 协议直接与提交服务器通信 |
 | 系统 Python 为 3.10，vibe-submit 需要 tomllib（Python 3.11+） | MCP 服务器启动失败 | 指定 Python 3.13 路径运行 |
 | 上级目录会话（019f92b1）未被自动收录 | 缺失早期规划阶段对话 | 编写会话总结文件 `docs/session-summary.md` 并补入项目 |
 | 10MB+ 提交包上传超时 | force 覆盖提交失败 | 分步提交：先提项目目录（~6MB），会话总结以文件形式包含 |
