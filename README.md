```bash

# 打开 http://localhost:4000
```

## 项目结构

```
├─ _config.yml           → 站点配置
├─ _pages/               → 页面内容
│  ├─ about.md           → 首页（时间线 + 自我介绍）
│  ├─ portfolio.html     → 项目经历
│  ├─ cv.md              → 简历
│  └─ contact.md         → 联系方式
├─ _sass/theme/          → 主题样式（蓝绿色系）
├─ assets/css/main.scss  → 自定义样式
├─ docs/                 → 作业规格文档
└─ screenshots/          → 验收截图
```
