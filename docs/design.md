## 2. 视觉风格

| 项目 | 选择 |
|------|------|
| 整体风格 | 两色搭配，马卡龙色系，低饱和度 |
| 主色 | 蓝绿色系 #5B8C8C（主色，用于标题、导航、强调元素） |
| 辅色 | 暖调米白 #F5F0EB（用于背景区隔、卡片底色） |
| 文字色 | 深灰 #2C3E50（正文）、中灰 #5D6D7E（辅助文字） |
| 字体 | 系统默认字体栈（Jekyll 模板自动处理） |
| 深色模式 | 跟随用户系统设置（`darkmode: true`），深色模式下调整蓝绿色明度 |
| 图标 | Font Awesome 图标（模板内置） |

### 配色理由
- 蓝绿色系传达沉稳、专业、可信赖感，符合金融科技 + AI 交叉背景
- 低饱和度马卡龙调性在两色搭配下保持柔和、不刺眼
- 米白辅色避免纯白的冷硬感，增加页面的亲和力
- 整体克制用色，让内容成为视觉焦点

## 5. 响应式与移动端

- **断点策略**：使用 Academic Pages 模板内置的响应式断点
- **移动端检查重点**：
  - 时间线在窄屏下保持可读
  - 技能标签不溢出
  - 联系方式（邮箱、电话）可点击
  - 导航栏折叠为汉堡菜单
- **桌面端检查重点**：
  - 侧边栏与主内容比例合理
  - 项目卡片三列布局正常
  - 无横向溢出
